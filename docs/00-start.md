# 00. С чего начать

## Зачем этот проект

Красивый анимированный фон, «живая» картинка или карточка, которая наклоняется за курсором, —
обычно это часы поиска примеров, подгонки под свои цвета и борьбы с производительностью.
3D-конструктор превращает это в три шага:

1. **Выбрать** эффект в Студии.
2. **Подкрутить** ползунки — сразу видно результат.
3. **Забрать код** и вставить в проект.

## Словарь в одну строку

| Слово | Простыми словами |
| --- | --- |
| **GPU, видеокарта** | Чип, который умеет делать одно и то же действие для миллионов пикселей одновременно |
| **WebGL2** | Способ, которым JavaScript в браузере отдаёт работу видеокарте |
| **Шейдер** | Маленькая программа, которая выполняется на видеокарте. Пишется на языке GLSL |
| **Фрагментный шейдер** | Шейдер, который отвечает на вопрос «какого цвета этот пиксель?» — и запускается для каждого пикселя |
| **GLSL** | Язык шейдеров. Похож на C: типы `float`, `vec2`, `vec3`, функции `sin`, `mix`, `smoothstep` |
| **uniform** | Переменная, которую JavaScript передаёт в шейдер. Одна на все пиксели: время, размер, цвет из ползунка |
| **vec2 / vec3 / vec4** | Наборы из 2, 3, 4 чисел. `vec2` — точка (x, y), `vec3` — цвет (r, g, b) |
| **uv** | Координаты пикселя в долях: (0, 0) — левый нижний угол, (1, 1) — правый верхний |
| **Шум (noise)** | «Плавная случайность»: соседние точки получают похожие значения. Основа облаков, дыма, воды |
| **fbm** | Несколько слоёв шума разного масштаба, сложенные вместе: крупные формы + мелкие детали |
| **Квад, полноэкранный квад** | Прямоугольник на весь холст. Мы рисуем его одним треугольником (см. главу 03) |
| **Холст, canvas** | HTML-элемент `<canvas>`, на котором рисует WebGL |
| **DPR (device pixel ratio)** | Сколько физических пикселей экрана в одном CSS-пикселе. На ретине — 2 или 3 |
| **FBO, буфер кадра** | «Невидимый холст»: рисуем в него, а потом используем как картинку (для постобработки) |
| **Постобработка** | Второй шаг: готовый кадр ещё раз обрабатывается — добавляем зерно, свечение |
| **Рантайм** | Код, который запускает эффект: создаёт WebGL, крутит кадры, следит за мышью |
| **Экспорт** | Файл, который Студия собирает для вашего проекта |
| **Ленивая загрузка** | Код эффекта скачивается, только когда блок с эффектом подъезжает к экрану |

## Картина целиком

```
src/
├─ runtime/            ← то, что попадает в ваш проект
│  ├─ runtime.js       рантайм шейдерных эффектов и слайдов (без import — самодостаточный)
│  ├─ transition.js    переходы между секциями: прожигание, растворение, шторка
│  ├─ scene.js         рантайм 3D-сцен на three.js
│  ├─ three/           3D-эффекты: galaxy, swarm, morph, text-particles, glass
│  └─ tilt.js          наклон карточки на CSS
├─ effects/            ← каталог: каждый эффект — данные (шейдер + параметры + пресеты)
│  ├─ noise.ts  lava.ts  waves.ts  clouds.ts  space.ts  aurora.ts  plasma.ts
│  ├─ image-distort.ts  slides.ts  transitions.ts  three.ts  tilt.ts
│  └─ index.ts         список эффектов и категорий
├─ engine/             ← логика без интерфейса
│  ├─ params.ts        проверка значений, «Случайно», запись в адрес
│  ├─ codegen.ts       сборка файлов экспорта
│  └─ perf.ts          панель производительности
├─ studio/             ← интерфейс Студии (React)
│  ├─ App.tsx  Preview.tsx  Controls.tsx  CodeDrawer.tsx
└─ site/main.ts        главная страница
```

**Главная идея: эффект — это данные.** Вот (сокращённо) как описан «Шум»:

```ts
export const noise: EffectDef = {
  id: 'noise',
  name: 'Шум',
  category: 'Фоны',
  kind: 'quad',                       // полноэкранный шейдер
  params: {
    speed:  { type: 'number', label: 'Скорость', min: 0, max: 2, default: 0.35 },
    colorA: { type: 'color',  label: 'Цвет 1', default: '#0b0820' },
  },
  presets: [{ name: 'Неон', values: { colorA: '#05010f' } }],
  fragment: `void main() { … fragColor = vec4(цвет, 1.0); }`,
}
```

Из этого описания **само** строится всё остальное:

- Студия рисует ползунок «Скорость» от 0 до 2 и палитру «Цвет 1»;
- рантайм объявляет в шейдере `uniform float uSpeed; uniform vec3 uColorA;` и каждый кадр
  передаёт туда значения;
- экспорт кладёт в файл шейдер и текущие значения.

Новый эффект — новый файл в `src/effects/`. Править интерфейс не нужно (рецепт — глава 09).

## Путь значения: от ползунка до пикселя

```
Вы двигаете ползунок «Скорость»
   │
   ▼  Controls.tsx: onChange(0.8)
App.tsx: setValues({ ...values, speed: 0.8 })
   │
   ├─▶ адрес страницы: ?e=noise&speed=0.8   (toSearch, replaceState)
   │
   ▼  Preview.tsx: instance.set(values)
runtime.js: values.speed = 0.8 → requestDraw()
   │
   ▼  следующий кадр, draw()
gl.uniform1f(uSpeed, 0.8)
   │
   ▼  видеокарта, для каждого пикселя
float t = uTime * uSpeed;   →   цвет пикселя
```

И когда вы нажимаете «Забрать код», те же `values` уходят в `generate()` и записываются в файл:

```js
const SPEC = { …, values: { "speed": 0.8, "colorA": "#0b0820", … } }
```
