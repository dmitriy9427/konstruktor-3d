# Учебник 3D-конструктора

Учебник написан для того, кто **ни разу не писал шейдер**. Каждая глава — от простого к
сложному, с примерами, которые можно вставить в Студию или в пустую HTML-страницу и увидеть.

| Глава | О чём |
| --- | --- |
| [00. С чего начать](00-start.md) | Словарь, картина целиком: из чего состоит проект и как данные идут от ползунка до пикселя |
| [01. Как пользоваться](01-use.md) | Студия, три формата экспорта, ленивая загрузка, как вставить эффект в сайт, React, CMS |
| [02. Шейдер для самых маленьких](02-shaders.md) | Что такое фрагментный шейдер, координаты, время, цвет, шум и fbm — по шагам |
| [03. Рантайм](03-runtime.md) | Разбор `runtime.js`: WebGL2, треугольник, uniform, цикл кадров, мышь с инерцией, экономия |
| [04. Эффекты](04-effects.md) | Как устроен каждый эффект: математика простыми словами и что делает каждый параметр |
| [05. Постобработка](05-post.md) | Второй проход: свечение, зерно, хроматическая аберрация, виньетка |

| [07. Студия](07-studio.md) | React-часть: состояние в адресе, контролы из схемы, превью, «Забрать код» |
| [08. Производительность](08-performance.md) | Панель FPS, что значат CPU/GPU мс, приёмы, которые держат 60 кадров |
| [09. Свой эффект](09-new-effect.md) | Рецепт: добавляем эффект «Плазма» с нуля — от шейдера до теста |
