# 13. Свой эффект и траектория

**Зачем:** каталог — это готовые эффекты. «Свой эффект» — пустой холст: пишете шейдер прямо в
Студии, ползунки появляются сами, «Забрать код» работает как у всех.

## Как начать

1. В каталоге — **«Свой эффект»** (первым пунктом).
2. **«Начать с…»** — шаблон («Градиент», «Кольца», «Шум», «Пустой») или **копия любого эффекта**
   каталога: его шейдер и все параметры, готовые к правке.
3. Правьте код — превью пересобирается через 0,4 с после паузы в наборе.

Доступно в шейдере то же, что у эффектов каталога (глава 02): `uTime`, `uResolution`, `uMouse`
(0…1), `uMouseActive`, `uHover`, `uScroll`, функции `hash`, `hash2`, `noise`, `fbm`, `rot`. Цвет —
в `fragColor`.

## Ползунки из комментариев

```glsl
// @param speed number 0 2 0.5 Скорость
// @param tint color #ff6b9d Оттенок
// @param glow boolean true Свечение
// @param mode select wave|rings|dots wave Узор
```

| Тип | Дальше в строке | В шейдере |
| --- | --- | --- |
| `number` | мин, макс, по умолчанию, подпись | `uniform float uSpeed` |
| `color` | `#rrggbb`, подпись | `uniform vec3 uTint` |
| `boolean` | `true` / `false`, подпись | `uniform float uGlow` (0 или 1) |
| `select` | варианты через `\|`, по умолчанию, подпись | `uniform float uMode` (номер варианта) |

Объявлять `uniform` не нужно — рантайм делает это сам (глава 03). Ошибка в строке `@param`
показывается под редактором: «строка 3: number — мин макс по-умолчанию…».

Как это устроено (`src/engine/custom.ts`): регулярное выражение находит строки `// @param`,
каждая превращается в описание параметра — то же, что у эффектов каталога. Дальше Студия
работает с ним как с любым эффектом: ползунки, адрес, экспорт.

## Ошибки компиляции — в строках редактора

Видеокарта сообщает `ERROR: 0:57: 'oops' : undeclared identifier` — номер строки **всего**
шейдера, а он начинается с нашей «шапки» (версия, общие функции, uniform). Студия считает,
сколько строк в шапке, и вычитает:

```ts
const prefix = buildFragment({ fragment: '', params }).split('\n').length - 1
message.replace(/ERROR: \d+:(\d+):/g, (_, line) => `Строка ${line - prefix}:`)
```

## Где хранится код

В адресе: `?e=custom&code=…` — код в base64 (через UTF-8, чтобы работала кириллица в
комментариях; `+/` заменены на `-_` — безопасно для ссылки). Ссылка «Поделиться» открывает
Студию с вашим эффектом. Плюс черновик в браузере (`localStorage`): закрыли вкладку — код на месте.

## Траектория (для всех эффектов)

В «Общих» — **«Траектория»**: круг, восьмёрка, волна или своя (кнопка «Рисовать» → клики по
превью, путь подсвечивается пунктиром). «Точка влияния» — то, на что эффект реагирует мышью, —
летит по пути. «Всегда по пути» — мышь не перебивает; иначе мышь главная, пока она над эффектом.

В своём шейдере траектория работает автоматически: это просто `uMouse`. Устройство — глава 03.
