# 14. Курсоры

**Зачем:** курсор — то, что пользователь видит всё время. Пять вариантов, от лёгкого (без
WebGL) до жидкого.

| Курсор | Как устроен | Файл |
| --- | --- | --- |
| Жидкость, Дым | WebGL: прозрачный холст поверх страницы + симуляция краски | `src/effects/cursors.ts` |
| След из частиц | 2D-холст, частицы с физикой | `src/runtime/cursor.js` |
| Кольцо | две метки (div) и `mix-blend-mode: difference` | `src/runtime/cursor.js` |
| Фонарик | слой с `radial-gradient` | `src/runtime/cursor.js` |

## Жидкость и дым: краска, которую уносит поток

Это тот же рантайм, что у фонов, с двумя новыми вещами.

**1. Прозрачный холст.** Опция `transparent: true`: контекст WebGL с альфа-каналом, шейдер
пишет цвет, **уже умноженный на прозрачность** (premultiplied alpha) — так браузер правильно
смешивает холст со страницей под ним. Холст `position: fixed`, `pointer-events: none` — клики
проходят сквозь него к кнопкам и ссылкам. Постобработки у прозрачного холста нет: она пишет
непрозрачный кадр.

**2. Симуляция краски** (та же «пинг-понг» схема, что у воды в «Волнах», глава 04). В
текстуре: `rgb` — краска, `a` — её плотность. Каждый шаг:

```glsl
vec2 vel = curl(q * uScale, uTime * 0.05) * uSwirl * 0.05;   // вихревой поток
vel.y += uRise * 0.35;                                         // дым поднимается
vel += uMouseVel * near;                                       // мазок мыши тащит краску
vec4 prev = texture(uState, uv - vel * dt);                    // адвекция: «откуда принесло»
prev *= pow(uFade, dt * 60.0);                                 // тает
prev += краска * near * скорость мыши;                         // новый мазок
```

- **Ротор шума (curl).** Если взять скорость прямо из шума, краска собиралась бы в кучи и
  исчезала в «стоках». Ротор `(∂n/∂y, −∂n/∂x)` — поле без стоков и источников: краска только
  кружится, как в настоящей жидкости.
- **Адвекция «назад»:** новое значение в точке — то, что было в точке `uv − v·dt`. Так
  считать проще и устойчивее, чем двигать каждую каплю вперёд.
- **Краски тем больше, чем быстрее движение мыши** (`uMouseVel`) — стоящая мышь ничего не
  рисует, взмах оставляет густой мазок.

## След из частиц

На каждом кадре — сколько пикселей прошла мышь; частицы рождаются **по пути** (`густота` на
единицу длины), а не «по одной на событие» — поэтому быстрый взмах даёт ровный след, а не
редкие точки. У частицы скорость (часть скорости мыши + случайный разлёт), гравитация,
сопротивление воздуха `v *= exp(−2.2·dt)`, вращение и время жизни. Клик — салют: частицы по
кругу. «Свечение» — `globalCompositeOperation = 'lighter'`: где частиц много, ярче.

## Кольцо: цвет наоборот контенту

Точка стоит точно под курсором, кольцо догоняет с инерцией. Над ссылками и кнопками кольцо
растёт (`closest('a, button, …')`). Главный приём — `mix-blend-mode: difference`: цвет метки
вычитается из цвета под ней. Белое кольцо на белой карточке становится чёрным, на чёрной —
белым, на градиенте — инвертированным градиентом. Курсор виден на любом фоне без единой
строчки логики.

## Фонарик

Слой поверх страницы с фоном

```css
radial-gradient(circle 180px at X Y, rgba(тёплый свет) 0%, transparent 65%, rgba(темнота, 0.88) 100%)
```

Каждый кадр меняются только координаты. Ни холста, ни WebGL — самый дешёвый курсор.

## Общее

- Курсор работает на всей странице (`mount()`) или только в блоке (`mount(блок)`).
- «Скрыть обычный курсор» — `cursor: none` на области.
- На тач-экранах лёгкие курсоры не включаются: мыши нет.
- «Уменьшить движение» — без следа и инерции.
