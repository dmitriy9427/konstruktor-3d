# 04. Эффекты

**Зачем:** понять, как устроен каждый эффект, и что на самом деле меняет каждый ползунок.
Код — `src/effects/*.ts`, поле `fragment`.

## «Шум» — `noise.ts`

**Идея:** domain warping — шум от координат, сдвинутых шумом (глава 02, шаг 9). Формы
закручиваются, как дым.

```glsl
vec2 q = vec2(fbm(p + t), fbm(p + vec2(5.2, 1.3) - t));   // первое искажение
vec2 r = vec2(fbm(p + uWarp * q + …), fbm(p + uWarp * q + …)); // искажение искажения
float n = fbm(p + uWarp * r);                              // итоговый узор
n = clamp((n - 0.5) * uContrast + 0.5, 0.0, 1.0);          // контраст вокруг середины
```

| Параметр | Что меняет |
| --- | --- |
| Скорость | Как быстро течёт узор |
| Масштаб | Крупные клубы (меньше) или мелкие разводы (больше) |
| Закрутка (`warp`) | Насколько сильно координаты искажены: 0 — простое облако, 3–4 — мраморные вихри |
| Контраст | Резкость переходов между цветами |
| Цвета 1–3 | Тень, основной, акцент (цвет 3 появляется там, где и узор, и первое искажение `q` сильные) |

Мышь притягивает разводы к себе.

## «Лава» — `lava.ts`

**Идея: метаболы.** У каждой капли есть «поле силы», которое убывает с расстоянием:

```glsl
field += r * r / dot(d, d);     // r — радиус капли, d — от капли до пикселя
```

Поля всех капель **складываются**. Где сумма больше 1 — там лава. Когда две капли сближаются,
между ними сумма полей тоже больше 1 — появляется плавная перемычка. Капли не пересекаются
кругами, а **сливаются**.

```
 одна капля:   ( )        две рядом:   (  )(  )  →  (‾‾‾‾‾‾)
                                       поля сложились — перемычка
```

Каждая капля ходит по своей фигуре Лиссажу (`sin` с разной частотой по x и y) — движение не
повторяется долго. Ещё одна капля «сидит» на курсоре.

| Параметр | Что меняет |
| --- | --- |
| Капель | Сколько капель (до 12; цикл до константы + `break` — так работает везде) |
| Размер | Радиус капли |
| Мягкость края | Ширина `smoothstep` вокруг порога 1 |
| Свечение | Ореол вокруг капель (поле от 0.25 до 1 — «почти лава») |
| Ядро / Край | Цвет в центре (поле ≥ 3) и у края (поле ≈ 1) |

## «Волны» — `waves.ts`

**Идея:** настоящая водная гладь до горизонта, но без 3D-модели — всё в одном шейдере.

**1. Куда смотрит пиксель.** Камера висит на высоте 1.2 и смотрит вниз-вперёд. Для каждого
пикселя строим луч и находим, где он пересекает воду (плоскость y = 0):

```glsl
vec3 rd = normalize(vec3(p.x, p.y - 0.58, 1.0));   // направление луча
float dist = 1.2 / -rd.y;                          // до воды
vec2 x = rd.xz * dist;                             // точка на воде
```

Пиксели внизу экрана смотрят на воду рядом, вверху — вдаль.

**2. Высота воды.** Сумма 6 волн разного направления и длины. Форма волны — `exp(sin(φ) − 1)`:
острый гребень и пологая впадина, как у морской волны (у простого `sin` гребень и впадина
одинаковые — выглядит как «стиральная доска»).

**3. Наклон (нормаль).** Берём высоту чуть левее/правее и ближе/дальше — разница даёт наклон
поверхности. Шаг растёт с расстоянием: вдали мелкая рябь не превращается в мерцающий шум.

**4. Освещение.**

- **Френель:** под острым углом (вдали) вода — зеркало и отражает небо, под прямым (рядом) —
  видно глубину. `fresnel = 0.04 + 0.96 * pow(1 − cos, 5)` — классическое приближение Шлика.
- **Блик солнца:** отражённый луч `reflect(rd, n)` смотрит на солнце → `pow(…, 140)` — узкая
  яркая дорожка.
- **Дымка:** вдали цвет уходит в цвет неба — горизонт мягкий.

**5. Мышь:** в точке воды под курсором расходятся круги.

| Параметр | Что меняет |
| --- | --- |
| Скорость | Как быстро бегут волны |
| Частота | Длина волн: больше — мельче рябь |
| Высота | Насколько круты склоны (сила нормалей) |
| Неровность | Острота гребней (степень в `exp`) |
| Солнце (угол) | Где солнце: слева, по центру, справа — куда ляжет дорожка |
| Блики | Яркость солнечной дорожки |
| Глубина / Мель / Блик | Цвет воды в тени, на свету и цвет солнца/неба |

## «Облака» — `clouds.ts`

**Идея:** плотность облака — fbm с лёгким искажением. «Покрытие» сдвигает порог: где
плотность выше порога — облако.

**Объём без 3D:** берём плотность чуть **выше** по экрану. Если там облако тоньше — мы у
верхушки, её освещает солнце → светлее. Если толще — мы внизу облака → тень. Толща облака
темнее, края чуть светятся («серебряная кромка»).

Курсор «раздвигает» облака: рядом с ним плотность уменьшается.

| Параметр | Что меняет |
| --- | --- |
| Ветер | Скорость дрейфа |
| Покрытие | Сколько неба закрыто |
| Мягкость | Резкий край или пушистый |
| Масштаб | Размер облаков |
| Небо вверху / внизу | Градиент неба |
| Свет / Тень облака | Освещённая и теневая сторона |

## «Космос» — `space.ts`

**Звёзды — сетка.** Плоскость делится на клетки; в каждой — максимум одна звезда в случайном
месте клетки (`hash2(номер клетки)`). Часть клеток пустая — это «плотность». Яркость и размер
— тоже случайные, мерцание — `sin(время × случайная частота)`.

**Параллакс — три слоя:** дальний (мелкая сетка, медленно), средний, ближний (крупные звёзды,
быстро). Мышь сдвигает ближние слои сильнее — ощущение глубины.

**Туманность** — два fbm разных цветов поверх фона.

| Параметр | Что меняет |
| --- | --- |
| Полёт | Скорость движения слоёв |
| Плотность звёзд | Доля непустых клеток |
| Мерцание | Амплитуда мигания |
| Туманность | Яркость туманности (0 — только звёзды) |
| Параллакс мыши | Насколько слои реагируют на курсор |

## «Сияние» — `aurora.ts`

**Три ленты-занавеса.** У каждой — волнистый нижний край (fbm, плывущий во времени). Ниже
края — ничего, выше — свет, который затухает (`exp(−dy × k)`).

**Лучи** — шум, зависящий только от x: вдоль ленты появляются вертикальные полосы, как у
настоящего сияния.

**Цвет по высоте:** у края — цвет 1, выше — цвет 2, верхняя лента — цвет 3. Сложение лент
проходит через `1 − exp(−col)` — яркость не «выгорает» в белое.

| Параметр | Что меняет |
| --- | --- |
| Ширина волн | Насколько растянуты изгибы лент |
| Яркость | Общая сила |
| Центр по X / Y | Где сияние ярче и на какой высоте ленты — ставьте туда заголовок |

## «Плазма» — `plasma.ts`

Сумма четырёх синусов (полосы по x, по y, по диагонали и круги от центра, который ходит сам
или следует за мышью), раскрашенная градиентом «тень → основной → блик». Разобрана по шагам
в главе [09. Свой эффект](09-new-effect.md).

| Параметр | Что меняет |
| --- | --- |
| Масштаб | Размер узора |
| Полосы | Сколько цветных полос на экране |
| Блики | Насколько гребни уходят в цвет «Блик» |

## «Плывущая картинка» — `image-distort.ts`

Холст лежит **поверх** `<img>`: картинка остаётся в разметке (её видят поисковики и
пользователи без WebGL), а шейдер рисует её искажённую копию.

Сила эффекта умножается на `uHover` — плавно 0 → 1 при наведении. Без курсора фото обычное.

| Режим | Как работает |
| --- | --- |
| Волна | Координаты картинки сдвигает поле fbm — «жидкость» |
| RGB-сдвиг | Красный канал берём чуть в одну сторону от курсора, синий — в другую |
| Рябь | `sin(расстояние × 60 − время)` — круги от курсора сдвигают картинку |

| Параметр | Что меняет |
| --- | --- |
| Радиус | Зона вокруг курсора, где работает искажение |
| Приближение | Картинка чуть увеличивается при наведении — «оживает» |
| Всегда, без наведения | Эффект работает постоянно (для фонового фото) |

## «Наклон 3D» — `tilt.ts` + `src/runtime/tilt.js`

Без WebGL: только CSS `transform`. Можно повесить хоть на сто карточек.

```
курсор над карточкой → доля от центра (−1…1) → rotateX / rotateY
```

Значения догоняют цель пружиной на `requestAnimationFrame` — наклон плавный даже при рывке
мыши. **Блик** — полупрозрачный радиальный градиент (`mix-blend-mode: soft-light`), который
едет за курсором.

На тач-экранах (`hover: none`) и при «уменьшить движение» ничего не делает.

| Параметр | Что меняет |
| --- | --- |
| Угол | Максимальный наклон, ° |
| Перспектива | Меньше — сильнее «3D» (как близко камера) |
| Увеличение | Масштаб при наведении |
| Инерция | Плавность |
| Блик | Сила блика |
| Наклон от курсора | Карточка «убегает» от курсора, а не тянется к нему |
| Оси | Наклон по обеим осям или только по одной |
