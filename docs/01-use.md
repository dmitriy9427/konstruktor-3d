# 01. Как пользоваться

## Студия за минуту

```
┌────────────┬──────────────────────────────┬───────────────┐
│ Каталог    │                              │ Пресеты       │
│  Фоны      │        Живое превью          │ 🎲 Случайно   │
│  Изображ.  │   (двигайте мышью над ним)   │ Ползунки      │
│  Без WebGL │                              │ Общие         │
└────────────┴──────────────────────────────┴───────────────┘
              FPS · Поделиться · Забрать код
```

| Кнопка | Что делает |
| --- | --- |
| **Пресет** («Неон», «Закат»…) | Готовый набор значений — хорошая отправная точка |
| **🎲 Случайно** | Числа — в середине диапазона (крайности обычно некрасивы), цвета — гармоничная палитра |
| **Сбросить** | Значения по умолчанию, в том числе общие настройки |
| **Своя картинка…** | Для «Плывущей картинки» и «Наклона 3D»: файл не уходит в сеть, живёт только во вкладке |
| **FPS** | Панель производительности в углу превью (глава 08) |
| **Поделиться** | Копирует ссылку: в ней эффект и все изменённые значения |
| **Забрать код** | Ящик с файлами для проекта |

**Адрес — это сохранение.** Любое изменение сразу попадает в адрес: `studio.html?e=lava&speed=0.6&colorA=ffd166&_grain=0.2`.
В адрес пишутся **только отличия от умолчаний**, поэтому ссылка короткая. Общие настройки — с
префиксом `_`, чтобы не пересечься с параметрами эффекта. Перезагрузили страницу — всё на месте.

### Общие настройки

| Настройка | Что значит |
| --- | --- |
| **Следовать за мышью** | Выключили — эффект не реагирует на курсор (полезно для фона под формой) |
| **Инерция мыши** | 0 — мгновенно, 0.6 — очень плавно, «с запаздыванием» |
| **Качество (плотность пикселей)** | Потолок DPR. 1 — как CSS-пиксели, 2 — как ретина. Мягким фонам хватает 1–1.5 |
| **Свечение / Зерно / Аберрация / Виньетка** | Постобработка (глава 05). 0 — выключено и ничего не стоит |

## Три формата экспорта

### 1. JS-модуль — для любого сайта

Получаете два файла: `effect.js` (весь код эффекта) и `index.html` (пример подключения).

```html
<section id="hero">
  <div id="hero-bg" class="hero__bg"></div>
  <h1>Заголовок поверх эффекта</h1>
</section>

<style>
  #hero { position: relative; min-height: 100vh; isolation: isolate; }
  /* Заглушка, пока эффект не загрузился, — фон того же цвета. */
  .hero__bg { position: absolute; inset: 0; z-index: -1; background: #0b0820; }
</style>

<script type="module">
  import { mount } from './effect.js'
  mount(document.querySelector('#hero-bg'))
</script>
```

Что здесь происходит:

- `mount(элемент)` создаёт внутри элемента `<canvas>` на весь его размер и запускает эффект;
- `z-index: -1` кладёт фон **под** заголовок;
- `isolation: isolate` нужен, чтобы «−1» не провалился под фон всей страницы;
- `background` у заглушки — ваш первый цвет из Студии: пока код грузится, пользователь видит не
  белое пятно, а подходящий фон.

`mount()` возвращает управление эффектом:

```js
const effect = mount(document.querySelector('#hero-bg'), { quality: 1 }) // переопределить настройку
effect.set({ speed: 1.2, colorA: '#ff0066' })   // поменять параметры на лету
effect.setOptions({ mouse: false })             // общие настройки
effect.pause(); effect.play()
effect.destroy()                                // убрать холст и отпустить видеокарту
```

### 2. React

Файлы `Effect.tsx` и `effect.js` положите рядом:

```tsx
import { Effect } from './effects/aurora/Effect'

export function Hero() {
  return (
    <section className="hero">
      <Effect className="hero__bg" />
      <h1>Заголовок</h1>
    </section>
  )
}
```

Компонент сам создаёт эффект в `useEffect` и уничтожает его при размонтировании. `StrictMode`
безопасен: React в разработке монтирует компонент дважды — эффект корректно пересоздаётся.

Для «Плывущей картинки»: `<Effect src="/photo.jpg" alt="Описание" />`. Для наклона:
`<Effect><h3>Карточка</h3></Effect>`.

### 3. Веб-компонент — для CMS и HTML без сборки

```html
<script type="module" src="./effect.js"></script>

<k3d-aurora lazy style="height: 100vh"></k3d-aurora>
```

Тег регистрируется при подключении файла. Работает в Tilda, WordPress, обычном HTML — везде,
где можно вставить свой код. Атрибут `lazy` — запуск, когда элемент подъезжает к экрану.

## Ленивая загрузка — что это и зачем

**Без ленивой загрузки:** браузер открывает страницу → сразу скачивает `effect.js` (≈ 8 КБ в
gzip) → создаёт WebGL → начинает рисовать. Даже если эффект в самом низу страницы и
пользователь до него не долистает.

**С ленивой загрузкой** (галочка в «Забрать код»):

```js
const target = document.querySelector('#hero-bg')
const observer = new IntersectionObserver(async ([entry]) => {
  if (!entry.isIntersecting) return       // блок ещё далеко — ждём
  observer.disconnect()                   // сработали один раз — больше не следим
  const { mount } = await import('./effect.js')   // скачиваем код только сейчас
  mount(target)
}, { rootMargin: '50% 0px' })             // «подъезжает» = за полэкрана до появления
observer.observe(target)
```

- `IntersectionObserver` — встроенный в браузер «наблюдатель»: сообщает, когда элемент
  пересекает видимую область. Дёшево, без обработчика прокрутки.
- `rootMargin: '50% 0px'` расширяет видимую область на полэкрана вверх и вниз — код успевает
  скачаться до того, как блок покажется. Пользователь не видит задержки.
- `import('./effect.js')` — **динамический импорт**: файл скачивается в момент вызова, а не
  при загрузке страницы.
- Пока код не пришёл, видна заглушка (фон того же цвета).

Итог: первая загрузка страницы быстрее, видеокарта не занята эффектами за экраном.

> Для первого экрана ленивая загрузка почти ничего не даёт (блок и так виден сразу), но и не
> мешает. Для эффектов ниже по странице — включайте всегда.

## Если у пользователя нет WebGL2

`mount()` ловит ошибку, пишет предупреждение в консоль и убирает холст. Остаётся то, что под ним:
заглушка с цветом фона или ваша `<img>` для «Плывущей картинки». Страница не ломается.

## Уважение к пользователю

- Включено «Уменьшить движение» в системе → эффект рисует один неподвижный кадр.
- Эффект за экраном → кадры не рисуются вообще (ноль нагрузки).
- Кадры не успевают → плотность пикселей снижается сама (глава 03).
- Наклон карточки на тач-экранах выключен: без курсора он только мешает прокрутке.
