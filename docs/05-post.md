# 05. Постобработка

**Зачем:** четыре дешёвых приёма, которые сильно меняют картинку. Код — `POST_FRAGMENT` в
`runtime.js`.

## Как устроено: два прохода

```
проход 1: шейдер эффекта ──▶ FBO (невидимый холст, текстура)
проход 2: шейдер post  ── читает текстуру ──▶ экран
```

Почему нельзя сразу? Свечению и аберрации нужны **соседние** пиксели, а фрагментный шейдер
знает только свой. Поэтому сначала рисуем весь кадр в текстуру, потом читаем из неё что угодно.

Если все четыре ползунка на нуле — второго прохода нет вообще (`postEnabled()`), эффект рисуется
прямо на экран. Постобработка ничего не стоит, пока выключена. В панели FPS это видно: `draw 1`
без постобработки, `draw 2` — с ней.

## Хроматическая аберрация

У дешёвых объективов красный и синий свет фокусируются в разных местах — по краям кадра
появляются цветные каёмки. Имитация:

```glsl
vec2 dir = uv - 0.5;                       // от центра к краю
float ca = uChroma * 0.008;
vec3 col = vec3(
  texture(uScene, uv + dir * ca).r,        // красный — чуть наружу
  texture(uScene, uv).g,                   // зелёный — на месте
  texture(uScene, uv - dir * ca).b         // синий — чуть внутрь
);
```

В центре сдвига нет (`dir` = 0), к краям — больше. Как у настоящей линзы.

## Свечение (bloom)

Яркие места «расплываются» светом вокруг себя:

```glsl
for (int i = 0; i < 12; i++) {                         // 12 направлений по кругу
  vec2 o = vec2(cos(a), sin(a)) / uResolution;
  glow += max(texture(uScene, uv + o * 6.0).rgb - 0.5, 0.0);        // ближнее кольцо
  glow += max(texture(uScene, uv + o * 16.0).rgb - 0.5, 0.0) * 0.6; // дальнее кольцо
}
col += glow / 12.0 * uBloom * 1.6;
```

- `- 0.5` и `max(…, 0)` — светятся только яркие пиксели (ярче половины);
- соседи берутся по двум кольцам — 24 чтения текстуры на пиксель.

Это «лёгкий» bloom. «Настоящий» делается уменьшением кадра в несколько раз и размытием
каждой копии (несколько FBO) — красивее, но дороже и сложнее. Для фонов хватает лёгкого.

## Виньетка

Края кадра темнее — взгляд тянется к центру:

```glsl
col *= mix(1.0, smoothstep(1.15, 0.2, length(dir) * 1.35), uVignette);
```

## Зерно

Шум, который меняется **каждый кадр** — как зерно плёнки:

```glsl
col += (hash(gl_FragCoord.xy + fract(uTime * 7.0) * 113.0) - 0.5) * uGrain * 0.16;
```

Побочный плюс: зерно маскирует **полосы на градиентах** (banding). В тёмных плавных градиентах
8 бит на канал не хватает, видны ступеньки — лёгкое зерно (0.1–0.2) их скрывает.

## Рецепты

| Хочется | Попробуйте |
| --- | --- |
| «Кино» | Зерно 0.25, виньетка 0.5 |
| «Неон» | Свечение 0.6 на «Лаве» или «Шуме» с яркими цветами |
| «Глитч, ретро» | Аберрация 0.8 + зерно 0.3 |
| Убрать полосы на тёмном градиенте | Зерно 0.1 |
